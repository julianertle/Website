# Portfolio Source Code

This repository houses the source code for my personal portfolio website. The project is designed as a custom-built digital business card to demonstrate my technical capabilities and academic background through a live interface.

## 🛠 Technical Architecture

The application is built with a focus on performance, clean state management, and modern UI patterns:

- **Core:** React (Functional Components & Hooks)
- **Build Tool:** Vite for optimized bundling and fast Hot Module Replacement
- **Styling:** Tailwind CSS with a mobile-first responsive grid
- **Interactions:** \* `IntersectionObserver API` for scroll-triggered animations
  - `Typewriter-effect` for dynamic hero section rendering
  - Custom `Context API` providers for global Theme and Language state

## 📋 Key Features

- **Adaptive UI:** Integrated Dark and Light mode support with hardware-accelerated transitions.
- **Categorized Skill Cloud:** An interactive, state-driven skills section that highlights expertise in Development, Cyber Security, and Project Management.
- **Document Integration:** Secure handling and linking of academic reports and professional certifications (PSPO I, Pentest Reports).
- **Internationalization:** Structural support for multi-language toggling via a centralized translation system.
